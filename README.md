# 融与蚀：时间的空间 | Fusion & Dissolution: Spaces of Time

这是一个专为作家与读者打造的沉浸式、科幻质感的双向互动网页。本页面融合了两个科幻短篇故事《M》与《消防通道》的精神内核，通过前沿的 Web 交互技术，将文学阅读转化为一场声、光、电与思想共振的旅程。

## 🌟 页面特色 (Features)
- **声学麻醉系统 (Web Audio Drone Synth)**：基于 Web Audio API 实时合成的 85Hz 深海催眠低频与粉红噪波，伴随 LFO 缓慢呼吸颤噪，带给读者完全沉浸的听觉体验。
- **3D 荧光晶体星云 (Canvas Stromatolite Particle System)**：基于 HTML5 Canvas 实时计算渲染的 3D 层叠石矿体。读者可将自己的“执迷之物”化为文字粒子注入并环绕晶体自转。
- **气态蠕动实体 (Translucent Fog Entity)**：模拟消防通道内果冻雾状非人生命的波动。能够实时响应用户的鼠标移动，吞噬用户扔下的“虚拟烟头”，并根据楼层变动收缩膨胀。
- **全屏消融特效 (Dissolution CSS Filter)**：点击“强行进入它”可触发全屏色相偏转与模糊，搭配低频滤波器，完美模拟人机意识消解融合的失重感。
- **W827018 共同维护合约签署**：交互式签署电子条约，让渡肉身的所有权，签署数据通过浏览器 `localStorage` 进行本地持久化保存。
- **读者对话墙 (Neural Comments)**：一个科幻风格的留言信箱，读者可在此向虚空发射思想电波。

## 📦 如何下载并在本地运行 (How to Run Locally)
您只需要下载以下两个核心文件，并保持在同一目录下即可：
1. `index.html` - 包含所有的结构、样式、JS 粒子和音效算法。
2. `ore_and_mist.jpg` - 背景插图，提供氛围基调。

直接双击 `index.html` 即可在任意现代浏览器（Chrome、Safari、Edge、Firefox 等）中完美开启。本页面采用无外部依赖（No External CDN）设计，支持 100% 离线运行。

## 🚀 部署至 GitHub Pages (Deploy to GitHub Pages)
您可以非常简单地将此项目部署为免费的个人永久互动网址：

1. **新建仓库**：在 GitHub 上创建一个新的公开仓库（Repository），例如命名为 `fusion-and-dissolution`。
2. **上传文件**：将 `index.html`、`ore_and_mist.jpg` 和本 `README.md` 上传到该仓库的根目录。
3. **启用 GitHub Pages**：
   - 进入仓库的 **Settings**（设置）。
   - 在左侧菜单栏找到 **Pages**（页面）选项。
   - 在 **Build and deployment** 下的 **Source** 选择 `Deploy from a branch`。
   - 将 **Branch**（分支）设置为 `main`（或 `master`），目录选择 `/ (root)`，点击 **Save**（保存）。
4. **访问链接**：大约 1 分钟后，GitHub 会在页面上方为您生成专属的访问网址，例如：`https://<your-username>.github.io/fusion-and-dissolution/`。
